# Open-source experiments and adoption programme

The current programme has two simultaneous purposes:

1. learn from high-quality external repositories and individual skills
2. determine whether selected mechanisms, selected skills or whole repositories should become part of BASIL

These options are **not mutually exclusive**.

## Evaluation modes

For each external project BASIL may choose:

- **ADOPT WHOLE** — integrated package offers greater value/coherence than selective extraction
- **ADOPT SELECTED** — install specific upstream skills/components
- **ADAPT** — create a BASIL-specific derivative or wrapper
- **STUDY** — learn from the pattern without importing it
- **REJECT** — remove it after evidence shows insufficient value

Low-cost reversible installation deserves a lower evidential threshold than making BASIL structurally dependent on another project's runtime or data model.

## Immediate experiments

### mattpocock/skills
High-value candidates: Grilling/Grill-Me, Research, Writing for Agents, Code Review, Handoff and To-Questionnaire. The repo is explicitly designed around small composable skills and is MIT-licensed.

### obra/superpowers
High-value candidates: Verification Before Completion and Systematic Debugging. For BASIL, the first is generalised into **Evidence Before Claims**, not limited to code/tests. MIT-licensed.

### garrytan/gstack
Test CEO/strategic plan review logic in isolation first. Whole-package adoption remains open if its broader review/orchestration system proves worth the footprint. MIT-licensed.

### Leonxlnx/taste-skill
Candidate for a bounded full-package trial. It offers multiple design skills, including frontend taste, redesign, image-to-code, high-end/minimalist/brutalist variants and image-generation skills. The current default frontend skill is v2 experimental and opinionated, so isolate the trial from BASIL core architecture. MIT-licensed.

### cathrynlavery/diagram-design
Strong candidate for full-package trial. Its value is integrated: diagram-type selection, semantic patterns, style profiles, branding, import/export and a large editorial diagram library. Configure a BASIL profile and judge outputs on real architecture/evidence-flow problems. MIT-licensed.

## Test rule

Do not mine merely for the sake of mining. If the integrated whole is more valuable, use the whole. If one mechanism delivers nearly all the value with less interference, use the mechanism. Keep the experiment reversible until evidence justifies structural dependency.
