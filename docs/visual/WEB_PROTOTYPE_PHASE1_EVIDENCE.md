## What is established

Primary Drive evidence dated 19 August 2026 identifies the target environment as `https://project-basil.davidbarske.chatgpt.site/` and repeatedly calls it a **working deployment** / **working prototype**.

The formal frontend engineering review was not a speculative design brief. It reports observed behaviour in that deployment:

- task-card collisions and overlaps
- horizon changes snapping/collapsing instead of simulating descent
- strategy/persona selectors producing no observable functional or layout change
- narrow/homogeneous card geometry and insufficient vertical canvas
- weak visual distinction for Now and the near-term horizon
- no time scrub, accelerated simulation or timeline zoom/live ticking

The review then defines the Phase 1 remediation/acceptance direction: rigid collision boundaries with push-up stacking, dynamic gravity transitions, stronger temporal horizons, time simulation, zoomable timeline behaviour, strategy-frame wiring and canonical BASIL data binding.

The Milestone 1 governing baseline from the same date independently names the deployed site as the target environment and treats rigid contact physics and dynamic simulation as core directives.
