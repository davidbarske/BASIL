# Behavioural / Interaction Profile

**Owner:** BRIAN  
**Maturity:** tested optional analytical method

This capability may be invoked independently or as an optional downstream stage after MANUEL evidence closure and Meeting Intelligence.

Where source quality supports it, analysis may consider turn-taking, interruption, question/answer behaviour, challenge/correction/concession patterns, linguistic behaviour, acoustic-temporal behaviour, interactional influence, recurring patterns and longitudinal change.

Direct evidence outranks framework expectation. Speaking time is descriptive and must not be treated as dominance, authority or influence without separate evidence. Text-only material does not support non-verbal claims.
