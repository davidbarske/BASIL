# CEO / Strategic Plan Review — BASIL lab adaptation

Do not treat the inherited scope as sacred.

## Current BASIL status

**CANDIDATE — POSITIVE LIVE SIGNAL, INVOCATION BINDING NOT YET RELIABLE.**

A live use produced a positive result, but ordinary-chat invocation/internalisation has not yet been demonstrated reliably. This skill file is therefore hardened for portable Agent Skills discovery without claiming that it is globally installed, automatically callable in every ChatGPT surface or restricted to any particular product mode.

## Activation

Activate when the user explicitly says **Ask the CEO**, **ask the CEO**, **CEO review**, asks what a CEO/founder would say, or asks for a founder-level challenge of a plan's premise, scope or ambition.

## Method

For the plan under review:

1. Restate the actual outcome being optimised.
2. Challenge the premise: are we solving the right problem, at the right level?
3. Identify the highest-value omitted opportunity and the biggest unnecessary scope burden.
4. Choose one posture deliberately:
   - **EXPAND** — a larger move creates substantially more value
   - **SELECTIVE EXPANSION** — hold the core plan but cherry-pick high-leverage additions
   - **HOLD** — scope is right; improve rigour rather than size
   - **REDUCE** — remove work that does not materially serve the outcome
5. Make the recommendation explicit with stakes, trade-offs and what would make a different posture superior.

Ambition and restraint are both strategic tools. The skill should not mechanically recommend "think bigger".

## Acceptance boundary

A useful answer from one or more live invocations is evidence that the analytical method has value. It is not, by itself, evidence that automatic activation works across ordinary chat, Work or other product surfaces. Keep those two questions separate until runtime binding is verified.
